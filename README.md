# 📅 AI 디지털배움터 스케줄 관리

AI 디지털배움터 8개 기관의 수업 일정을 관리하는 웹 애플리케이션입니다.

## ✨ 주요 기능

- 🏫 **8개 기관** 수업 스케줄 통합 관리
- 📆 **주간 드롭다운** 으로 빠른 일정 확인
- 📅 **월별 달력 팝업** 으로 전체 일정 조회
- 📚 **커리큘럼 페이지** (시작반, 기초반, AI반)
- 🚫 공휴일 자동 제외 및 회차 밀림 처리

## 🔗 배포 링크

> **GitHub Pages**: [https://neigeyezz.github.io/ai-digital-schedule/](https://neigeyezz.github.io/ai-digital-schedule/)

## 🛠 기술 스택

- HTML5
- CSS3
- Vanilla JavaScript

