📥 코드에 반영 사용 방법

1. Live Server로 index.html을 열기 (우클릭 → Open with Live Server)

2. 브라우저에서 기관 정보를 자유롭게 편집 / 수정이 끝나면 "📥 코드에 반영" 버튼 클릭

3. schedule-data.js 파일이 다운로드되며, 다운로드된 파일을 D:\Git_Desktop\ai-digital-schedule 폴더에 덮어쓰기

4. 이렇게 하면 코드 파일에 최신 데이터가 반영, Git 커밋 → GitHub 푸시하면 끝입니다.

※ 주의!!!
⚠️ 이 버튼은 Live Server(http://)로 열었을 때만 작동합니다. 더블클릭(file://)으로 열면 fetch가 차단되어 안 됩니다. 앞으로는 Live Server로만 여세요.
